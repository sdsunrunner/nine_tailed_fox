# 页面结构与原型设计

> nine_tailed_fox — 信息架构、页面布局、原型指导

文档版本：v0.1（规划设计阶段）
最后更新：2026-08-11

---

## 1. 信息架构

### 1.1 全局导航结构

```
nine_tailed_fox
│
├── 项目工作台 (Project Hub)        ← 默认首页，剧目列表与进度
│   └── 剧目详情 (Project Detail)
│       │
│       ├── 剧本工作台 (Script Studio)
│       │   ├── 选题与大纲
│       │   ├── 分集列表
│       │   └── 分场编辑器
│       │
│       ├── 分镜工作台 (Storyboard)
│       │   ├── 镜头列表
│       │   └── 故事板视图
│       │
│       ├── 视觉设定 (Visual Assets)
│       │   ├── 角色卡
│       │   ├── 场景卡
│       │   └── 全局风格
│       │
│       ├── 生成中心 (Generation Center)
│       │   ├── 视频生成
│       │   ├── 配音生成
│       │   └── 配乐生成
│       │
│       ├── 素材资产库 (Asset Library)
│       │
│       └── 设置 (Settings)
│           └── AI Provider 配置
│
└── 全局设置 / 帮助
```

### 1.2 导航层级

- **L0**：项目工作台（剧目列表）
- **L1**：剧目详情（进入某部剧后，左侧切换各功能模块）
- **L2**：模块内页面（如剧本工作台内的「大纲」「分场编辑」）

## 2. 全局布局

### 2.1 顶层框架

```
┌─────────────────────────────────────────────────────────────────┐
│  顶部栏：Logo · 当前剧目名 · 全局搜索 · 通知 · 设置              │
├──────────┬──────────────────────────────────────────────────────┤
│          │                                                      │
│  左侧    │                                                      │
│  导航    │              主内容区                                │
│  (剧目级)│                                                      │
│          │                                                      │
│  · 概览  │                                                      │
│  · 剧本  │                                                      │
│  · 分镜  │                                                      │
│  · 视觉  │                                                      │
│  · 生成  │                                                      │
│  · 素材  │                                                      │
│  · 设置  │                                                      │
│          │                                                      │
└──────────┴──────────────────────────────────────────────────────┘
```

- **顶部栏**：全局信息与操作，始终可见
- **左侧导航**：进入剧目后出现，按流程顺序排列各模块
- **主内容区**：根据模块切换内容

### 2.2 交互模式

- **列表-详情模式**：剧目列表、镜头列表、素材列表等
- **编辑器模式**：剧本编辑、镜头编辑
- **画布模式**：故事板、生成预览
- **任务面板**：生成任务队列与进度（常驻右下角或抽屉）

## 4. 关键交互模式

### 4.1 AI 生成交互

所有 AI 生成操作遵循统一模式：

```
点击生成 → 显示生成中状态（进度/骨架屏）
         → 完成后展示结果
         → 用户选择：[采用] [重生成] [多方案对比] [手动调整]
```

### 4.2 任务进度通知

- 生成任务常驻「任务面板」（右下角浮窗或抽屉）
- 任务状态变化通过 WebSocket 实时更新
- 失败任务在概览页「待办/提示」区汇总

### 4.3 一致性传播提示

当视觉设定（角色/场景）变更时：

```
角色形象更新 → 弹窗提示：
"角色「林晓」形象已更新，以下 3 个镜头已生成的素材可能不一致：
 · 第2集 场3 镜头1（故事板图）
 · 第2集 场3 镜头2（故事板图 + 视频）
 · 第2集 场3 镜头4（视频）
[标记待重新生成] [暂不处理]"
```

### 4.4 批量操作

- 镜头故事板批量生成
- 视频片段批量生成
- 对白批量配音
- 素材批量导出

## 6. 原型设计指导

本节为后续高保真原型与前端开发提供指导：

### 6.1 视觉风格建议

- **整体风格**：专业工具感 + 创意感，深色模式优先（影视创作场景常用）
- **主色调**：建议深色背景 + 一个鲜明强调色（如琥珀色/青色）
- **布局**：信息密度适中，编辑区域最大化

### 6.2 响应式范围

- 桌面优先（创作工作流需要大屏）
- 平板/移动端仅做预览与轻量查看（后续扩展）

### 6.3 组件复用

建议建立统一组件库：
- 剧目卡片 / 镜头卡片 / 素材卡片
- 生成任务条 / 进度条
- AI 生成结果对比器（多方案）
- 结构化编辑器块（场景/对白/动作）
- Provider 选择器

### 6.4 空状态与引导

每个模块需设计空状态与新手引导：
- 首次进入剧目 → 引导从选题开始
- 首次进入分镜 → 引导自动拆镜
- 无 AI Provider 配置 → 引导配置
