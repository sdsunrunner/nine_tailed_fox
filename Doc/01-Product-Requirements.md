# 产品需求文档 (PRD)

## 0. 项目宗旨（2026-08-31 定版）

**专注《故事新编》**：九尾狐特化为鲁迅《故事新编》项目支持——**不做其他短剧**。视觉手册只保留 8 篇概念图定稿风格（每篇一个视觉手册，对应 8 种鲜明美术风格），每篇独立成片，对标《爱·死亡·机器人》。

- **成片形态**：每篇为 **10-30 分钟**的完整短片，独立成篇、风格鲜明（8 篇 8 种美术风格：蒋兆和写实水墨/汉画像石/白描枯山水/敦煌重彩/枯山水淡彩/水墨草书版刻/宣纸淡墨/皮影戏台）、制作精良、成片完整
- **分集仅技术切割**：MiniMax H3 导演台单次视频时长有限，成片按技术上限切段生产（每段 ≤5 分钟），切割点落在场景/镜头自然边界，非编剧结构
- **质量标准**：院线电影级剧本（整片三幕/人物弧光/视听化写作/整片节奏）、导演美学统一、跨镜资产一致性

### 路线图

- **短期（进行中）**：完成《铸剑》短片（鲁迅《故事新编》同名篇目）
- **中长期**：完成《故事新编》全部 8 篇的短片化——每篇一个独立成片（《铸剑》《奔月》《理水》《采薇》《出关》《非攻》《起死》《补天》），铸剑为其中一篇

### 1. 产品目标

### 1.1 核心目标

让**单个创作者**能够独立完成《故事新编》各篇从「剧本创意」到「音视频素材产出」的全流程生产，
通过 AI 深度辅助，将传统需要多工种协作的短片生产过程压缩为一人可控的工作流，
最终产出 8 篇 10-30 分钟、每篇一种鲜明美术风格、对标《爱·死亡·机器人》质感的完整成片。

### 1.2 成功指标（定性）

- **流程贯通**：剧本 → 分镜 → 音视频，数据自然流转，无需手工搬运
- **AI 增效**：每个核心环节都有 AI 生成/辅助能力，人工仅做精修
- **一致性保证**：角色形象、场景风格跨镜头/跨集保持一致
- **单人可用**：无需团队协作即可跑通全流程

## 2. 目标用户

### 2.1 用户画像

**主用户：精品短片创作者 / 独立制作人**

| 特征 | 描述 |
|------|------|
| 身份 | 短片编剧、独立内容创作者、小型工作室主理人 |
| 技能 | 具备剧本创作能力，但缺乏分镜/绘图/视频制作专业技能 |
| 痛点 | 全流程工种多、协作成本高、AI 工具分散、素材一致性难保证 |
| 目标 | 一人完成 10-30 分钟精品短片生产（对标《爱·死亡·机器人》质感），快速试错、持续产出 |
| 设备 | 个人电脑（含 GPU 更佳），浏览器访问 |

### 2.2 典型场景

- **场景 A：从零创作一部精品短片** — 创作者有一个灵感，从选题开始，AI 辅助生成整片大纲与剧本，拆分镜，生成视觉素材与音视频片段
- **场景 B：已有剧本转可视化** — 创作者手写剧本导入，系统辅助拆分镜、生成故事板与视频素材
- **场景 C：系列短片量产** — 同一风格体系下按篇目批量生产（如《故事新编》逐篇成片），资产与美学跨篇复用

## 4. 非功能需求

### 4.1 性能

- 剧本编辑器响应流畅，长剧本（数万字）不卡顿
- AI 生成任务异步执行，不阻塞界面交互
- 素材预览秒级加载（缩略图优先）

### 4.2 可用性

- 浏览器访问，无需安装客户端即可使用核心功能
- 本地 Agent 离线可用（本地模型路径下）
- 任务失败可重试，进度可观测

### 4.3 扩展性

- AI Provider 可插拔，新增模型/服务无需改业务代码
- 模块化设计，新环节（如剪辑）可后续接入
- 单人 → 协作的扩展预留（数据模型预留作者/权限字段）

### 4.4 数据与隐私

- 本地生成素材默认存储在本地，不上传云端
- 云端 API 调用产生的中间数据可配置是否留存
- 剧目资产可整体导出备份

## 5. 约束与假设

### 5.1 约束

- **AI 能力依赖外部**：剧本/图像/视频/TTS 能力由云端 API 或本地 ComfyUI 提供，质量受 Provider 影响
- **视频生成为 GPU 密集**：本地视频生成需要具备 GPU 的设备
- **流程不包含成片**：本期输出为素材，不含剪辑与成片导出

### 5.2 假设

- 用户具备基本的剧本创作能力，能判断与修改 AI 生成内容
- 用户能理解分镜、景别等基本影视术语
- 本地 Agent 用户可自行部署（提供部署文档）

## 6. 首期 MVP 范围

首期 MVP 聚焦 **跑通主链路**，验证「剧本 → 分镜 → 音视频」的端到端可行性：

```
新建剧目
  → AI 生成大纲与分集剧本
  → 分场剧本编辑
  → 自动拆分镜 + 镜头编辑
  → 角色卡 + 场景卡生成
  → 故事板生成
  → 视频片段生成（单镜头）
  → TTS 配音
  → 素材入库与预览
```

MVP 之外的功能标记为 🔜，在主链路验证后迭代。
