## 1. 主链路总览

```
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌──────────┐   ┌──────────┐   ┌─────────┐
│ 新建剧目 │ → │ 选题灵感 │ → │ 大纲生成 │ → │ 分集剧本  │ → │ 分场剧本  │ → │ 剧本定稿 │
└─────────┘   └─────────┘   └─────────┘   └──────────┘   └──────────┘   └────┬────┘
                                                                            │
                                                                            ▼
┌─────────┐   ┌──────────┐   ┌──────────────┐   ┌─────────────┐   ┌─────────────┐
│ 素材入库 │ ← │ 音视频生成│ ← │ 故事板生成    │ ← │ 视觉设定就绪 │ ← │ 自动拆分镜  │
└─────────┘   └──────────┘   └──────────────┘   └─────────────┘   └─────────────┘
```

主链路分两大阶段：
- **创作阶段**：剧目 → 选题 → 大纲 → 分集 → 分场 → 剧本定稿
- **生产阶段**：拆分镜 → 视觉设定 → 故事板 → 音视频生成 → 素材入库

> 两阶段并非严格串行：视觉设定可与分镜并行；故事板生成后可回溯修改剧本。流程支持回退与迭代。

## 2. 剧目生命周期

### 2.1 剧目状态流转

```
        ┌──────────┐
        │  草稿     │  新建剧目默认状态
        └─────┬────┘
              │ 开始创作（选题/大纲就绪）
              ▼
        ┌──────────┐
        │  创作中   │  剧本与分镜进行中
        └─────┬────┘
              │ 分镜完成、视觉设定就绪
              ▼
        ┌──────────┐
        │  生产中   │  音视频生成进行中
        └─────┬────┘
              │ 全部镜头素材生成完成
              ▼
        ┌──────────┐
        │  已完成   │  素材齐备，可导出
        └─────┬────┘
              │ 长期不再编辑
              ▼
        ┌──────────┐
        │  已归档   │
        └──────────┘
```

> 任何状态均可回退到前一状态（如「生产中」回退到「创作中」修改剧本）。

### 2.2 单集生命周期

```
待创作 → 剧本编写中 → 分镜中 → 生成中 → 已完成
```

每集独立推进进度，剧集间可并行（先完成第 1 集全流程，再做第 2 集）。

## 3. 创作阶段子流程

### 3.1 选题灵感

```
用户进入剧目 → 选题灵感面板
   ├── 方式 A：用户输入自己的选题/灵感
   ├── 方式 B：AI 根据题材/风格/趋势生成选题建议
   │            └── 用户从建议中选用 / 改写
   └── 选题确认 → 进入大纲生成
```

**AI 能力**：文本生成（LLM）— 根据题材/风格生成多个选题方案。

### 3.2 大纲生成

```
选题确认
   ▼
用户补充：剧名 / 题材 / 风格 / 目标集数 / 一句话梗概
   ▼
AI 生成大纲
   ├── 剧情主线
   ├── 主要人物设定（姓名/身份/性格/关系）
   └── 分集大纲（每集剧情概要）
   ▼
用户审阅与修改 → 大纲定稿
```

**AI 能力**：文本生成 — 结构化输出大纲与人物设定。

### 3.3 分集剧本

```
大纲定稿
   ▼
选择某集 → AI 生成本集剧情概要（基于分集大纲）
   ▼
用户修改确认 → 进入分场编辑
```

### 3.4 分场剧本

```
本集剧情概要
   ▼
AI 拆分为多个分场（场景/时间/人物）
   ▼
分场剧本编辑器
   每场包含：
   ├── 场景描述（地点/时间/氛围）
   ├── 出场人物
   ├── 对白（角色 + 台词）
   └── 动作/镜头提示
   ▼
用户编辑 / AI 续写 / AI 改写
   ▼
分场剧本定稿 → 进入生产阶段
```

**AI 能力**：文本生成 — 分场拆解、对白生成、续写改写。

## 4. 生产阶段子流程

### 4.1 自动拆分镜

```
分场剧本定稿
   ▼
选择某场 → AI 拆解为镜头序列
   每个镜头包含：
   ├── 镜头序号
   ├── 景别（远/全/中/近/特写）
   ├── 角度（平/俯/仰）
   ├── 运镜（固定/推/拉/摇/移）
   ├── 时长（秒）
   ├── 画面描述
   └── 对应对白/动作
   ▼
用户调整（增删/排序/合并/拆分/改字段）
   ▼
分镜定稿
```

**AI 能力**：文本生成 — 剧本到镜头的结构化拆解。

### 4.2 视觉设定就绪

可在拆分镜之前或并行进行。

```
视觉设定面板
   ├── 角色卡管理
   │    ├── 新建角色卡（名称/性格/外形描述）
   │    ├── AI 生成角色形象图（多方案）
   │    ├── 锁定形象 → 跨镜头生成保持一致
   │    └── 角色与剧本人物关联
   ├── 场景卡管理
   │    ├── 新建场景卡（名称/环境/氛围）
   │    ├── AI 生成场景图
   │    └── 场景与分场关联
   └── 全局风格设定（画风/镜头风格）
   ▼
视觉设定就绪 → 提供生成约束
```

**AI 能力**：图像生成 — 角色形象、场景图、风格图。

### 4.3 故事板生成

```
分镜定稿 + 视觉设定就绪
   ▼
逐镜头生成故事板图
   每镜头输入：
   ├── 镜头画面描述
   ├── 出场角色形象（视觉约束）
   ├── 场景图（视觉约束）
   └── 全局风格
   ▼
AI 生成分镜图
   ▼
用户审阅
   ├── 满意 → 保留
   ├── 不满意 → 重生成（可调参/换参考）
   └── 上传参考图替换
   ▼
故事板定稿
```

**AI 能力**：图像生成 — 带约束的分镜图生成（角色/场景一致性）。

### 4.4 音视频生成

#### 4.4.1 视频片段生成

```
故事板定稿
   ▼
逐镜头生成视频片段
   每镜头输入：
   ├── 分镜图（图生视频）或画面描述（文生视频）
   ├── 运镜指令
   └── 时长
   ▼
提交生成任务（批量可入队）
   ├── 路由到云端 API Provider，或
   └── 路由到本地 Agent → ComfyUI
   ▼
异步执行 + 进度回传
   ▼
生成结果预览
   ├── 多方案对比
   ├── 选用其一
   └── 重生成
   ▼
视频片段入库
```

**AI 能力**：视频生成 — 图生视频优先，文生视频备选。

#### 4.4.2 TTS 配音

```
分场剧本对白 + 角色音色绑定
   ▼
逐条对白生成配音
   输入：
   ├── 角色台词
   ├── 角色音色（与角色卡绑定）
   └── 情绪/语速参数
   ▼
AI 生成语音
   ▼
预览 / 重生成 / 选用
   ▼
配音素材入库，关联至镜头
```

**AI 能力**：语音合成（TTS）— 多角色音色。

#### 4.4.3 配乐生成

```
场景/镜头氛围
   ▼
AI 生成或推荐背景音乐
   ▼
预览 / 选用
   ▼
配乐素材入库
```

**AI 能力**：音乐生成 / 音乐检索。

### 4.5 素材入库

```
各环节生成物
   ├── 剧本/大纲（文本）
   ├── 分镜图（图片）
   ├── 视频片段（视频）
   ├── 配音（音频）
   └── 配乐/音效（音频）
   ▼
统一入库到素材资产库
   每个素材记录：
   ├── 类型 / 文件位置
   ├── 来源（哪个镜头/角色/场景）
   ├── 版本号
   └── 选用状态
   ▼
可按需检索 / 导出
```

## 5. 关键回退路径

流程非严格线性，支持以下回退与迭代：

| 触发 | 回退动作 |
|------|----------|
| 故事板生成不满意 | 修改镜头描述 → 重新生成分镜图 |
| 视频生成发现分镜不合理 | 回到分镜编辑 → 调整后重新生成 |
| 角色形象需调整 | 修改角色卡 → 影响所有关联镜头的生成 |
| 剧本修改 | 修改分场剧本 → 重新拆镜（受影响镜头） |

**一致性传播**：视觉设定（角色/场景）变更后，系统标记所有受影响的镜头，提示用户是否重新生成。

## 6. 任务异步执行模型

音视频/图像生成为耗时操作，统一采用异步任务模型：

```
用户提交生成请求
   ▼
创建任务（任务队列）
   ▼
Provider 路由（云端 / 本地 Agent）
   ▼
异步执行
   ├── 进度通过 WebSocket 实时推送
   └── 失败可重试
   ▼
完成 → 结果入库 → 通知用户
   ▼
用户预览 / 选用 / 重生成
```

**任务状态**：`排队中 → 执行中 → 成功 / 失败 → 已选用 / 已废弃`
