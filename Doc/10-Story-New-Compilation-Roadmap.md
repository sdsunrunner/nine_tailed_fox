# 中长期规划：鲁迅《故事新编》系列短片化

> 对标《爱·死亡·机器人》：每一篇独立成片，各篇拥有**鲜明且彼此不同的美术风格**，共用「精品短片」（10-30 分钟）生产体系与品质基线。

文档版本：v0.1（2026-08-31 规划设想）
最后更新：2026-08-31

## 0. 总体设想

**《故事新编》= 鲁迅的「爱·死亡·机器人」**。鲁迅以「古今杂糅」的笔法重写上古神话传说——把女娲、后羿、大禹、伯夷叔齐、眉间尺、老子、墨子、庄子放进日常化、荒诞化、讽刺化的现代视角里。这种「旧故事 × 新眼光 × 杂糅质感」的基因，天然适合做成**每篇一个独立成片、每篇一种鲜明美术风格**的系列短片。

**风格差异化原则**（对标《爱死机》）：
- 每篇**锁定一种主导美术风格**（水墨/版画/皮影/浮世绘/剪纸/青铜/雕塑感写实/木刻…），篇与篇之间视觉上完全可区分
- 每篇**锁定一位导演美学**（从九尾狐 12 位导演手册中选最契合的），动态影像语言与静态画风统一
- 全部篇目共享**同一生产基线**：院线级剧本（整片三幕/无每集钩子）、技术分段（每段 ≤5 分钟）、跨镜资产一致性

**篇目清单**（8 篇，创作顺序按难度与里程碑价值建议）：

| 序号 | 篇目 | 故事内核 | 状态 |
|:--:|------|------|:--:|

| 2 | 《奔月》 | 后羿射日英雄的婚后日常：英雄迟暮、嫦娥奔月 | 🔜 |

## 1. 各篇独立成片 · 美术风格与导演建议

> 视觉手册：九尾狐 art_skills（画风）；导演手册：story_skills（叙事+镜头语言）。以下「建议导演」均为九尾狐现有导演手册中的可选对象。

### 1.1 《铸剑》— 蒋兆和写实水墨 · 双导演分段（侯孝贤 × 徐克）

| 维度 | 建议 |
|------|------|
| **美术风格** | **蒋兆和写实水墨人物画**（2026-08-31 实测定稿）：写实造型严谨 + 中锋用笔 + 皴擦渲染 + 墨色干湿浓淡层次，悲悯厚重（《流民图》质感）；青灰冷调、褪色旧照片、阴天散射光；**高潮（鼎中大战）用写意水墨虚境**——无鼎无头，三个完整人形虚影在墨色漩涡中缠斗，狂放水墨线条 |
| **导演美学（双导演分段）** | **写实段 = 侯孝贤**（长镜头静观、留白、冷眼看生死——人物戏/场景/大出丧的克制苍凉）；**打斗段（鼎中大战）= 徐克**（快节奏、凌厉动作、场面调度——写意虚境搏杀的张力）。两段分别按各自导演手册生成，写实段占比约 85%、打斗段约 15% |
| **视觉 DNA** | 青灰/墨黑为主、一点血红（血与火）；大远景山水、框中框（王宫门洞）；写实人物+水墨笔墨；打斗段写意虚境+狂放墨线 |
| **独特性** | 全系列最「沉」的一篇：蒋兆和式写实水墨做全系视觉基线；双导演分段（侯式静观 + 徐式凌厉）为全系独有结构 |
| **参考** | 蒋兆和《流民图》笔墨 + 《刺客聂隐娘》克制暴力（写实段）+ 《新龙门客栈》凌厉动作（打斗段） |

## 2.5 各篇成片时长估算

> 估算依据：**故事戏剧容量**（事件数/冲突密度/人物规模/场面复杂度），而非原文线性换算——短片改编按「能讲清一个完整事件链」的最小必要时长设计。
> 换算基准：院线短片节奏约 **220-260 字剧本/分钟**，单场 1-3 分钟，全片三幕结构（建置 25% / 对抗 50% / 解决 25%）。
> 技术切割：每段 ≤5 分钟（MiniMax H3 上限），末段 ≤5 分钟；分段数 = ceil(时长/5)。

| 篇目 | 故事容量 | 建议成片时长 | 分段数 | 结构说明 |
|------|---------|:--:|:--:|------|
| **铸剑** | 大（复仇三幕 + 鼎中三头大战 + 王宫群像 + 送葬） | **18-22 分钟** | 4-5 段 | 全系容量最大：献头→搏杀→出丧三幕各自饱满；18 分钟打底，22 分钟给鼎中大战留足 |
| **理水** | 大（官场群像 + 治水工程 + 文化宫现场） | **18-20 分钟** | 4 段 | 群像讽刺戏事件密度高，但单场短促（嘴仗/汇报），18-20 分钟足够 |
| **补天** | 中大（创世 + 补天 + 崩塌重来） | **15-18 分钟** | 3-4 段 | 场面宏大（天地/海/彩石）但事件链简单（抟土→补天→再补），靠视觉奇观撑时长 |
| **奔月** | 中（英雄婚后日常 + 射日回忆 + 嫦娥奔月） | **15-16 分钟** | 3 段 | 双线：日常细琐（王家卫氛围）+ 回忆射日（传奇）；15 分钟节奏从容 |
| **非攻** | 中（墨子千里徒步 + 楚庭辩难） | **13-15 分钟** | 3 段 | 线性苦行史诗，路景 + 一场大辩论；13 分钟可压缩，15 分钟更舒展 |
| **采薇** | 中小（二人采薇 + 饿死首阳山） | **12-14 分钟** | 3 段 | 事件极少、情绪极浓：靠日常细节（采薇/对话/进食）与留白撑时长 |
| **出关** | 小（老子出关 + 关令挽留 + 青牛远去） | **10-12 分钟** | 2-3 段 | 近乎无冲突的哲思静默，超长镜头 + 留白；10 分钟是「静」的底线，再短不成篇 |
| **起死** | 小（庄子与骷髅辩难 + 起死闹剧） | **10-12 分钟** | 2-3 段 | 单场景嘴仗为主，靠台词机锋与皮影表演感撑起；10 分钟节奏刚好 |

**系列时长分布**：8 篇合计约 **111-129 分钟**，单篇 10-22 分钟，全部落在精品短片区间（10-30 分钟）。
- 建议按「容量梯度」编排播出顺序：小容量（起死/出关 10-12）→ 中容量（采薇/非攻/奔月 12-16）→ 大容量（补天/理水/铸剑 15-22），形成渐强的观感曲线。

**生产时的时长落地**：每篇立项时把「建议成片时长」填入项目设置（短片时长 = totalDurationMin），AI 自动按该时长控制剧本篇幅与分段数（每段 ≤5 分钟）。

## 3. 生产路径建议

### 3.1 顺序与里程碑
1. **《铸剑》**（进行中）→ 打通全流程：剧本→拆镜→资产→视频→成片，沉淀生产基线
2. **《奔月》** → 验证「风格分化」：同一生产体系换一套视觉手册+导演手册即可出不同质感
3. **《理水》《补天》** → 验证讽刺喜剧与宏大色彩两极
4. 其余篇目按序推进；每完成一篇，把该篇的「视觉手册 + 导演手册 + 资产风格」沉淀为可复用模板

### 3.2 工程侧配合
- 每篇 = 一个独立 Project；在项目设置中指定：视觉手册（画风）+ 导演手册（叙事）+ 短片时长（10-30 分钟）
- 每篇先通过「新增导演手册」与「新增视觉手册」生成/定制对应风格手册（已有能力：Bing 检索生成）
- 资产复用：跨篇共享基础资产（如《铸剑》的眉间尺/王宫在《理水》《补天》中按新画风重新生成，不直接复用成片资产——风格必须独立）
- 全系列共享：拆镜/分镜/视频工作流、H3 Director 分段生产、一致性机制

### 3.3 风险与应对
| 风险 | 应对 |
|------|------|
| 8 套风格手册工作量大 | 每篇先出「风格样张」（1 场景+1 角色按新画风生成），定稿后再铺开 |
| 画风切换导致系列感断裂 | 保留「鲁迅式杂糅」共同基因：古今杂糅细节（如《理水》的现代台词）贯穿各篇，形成隐性系列签名 |
| 皮影/木刻等风格对视频模型适配度未知 | 优先用实拍感强的风格（水墨/壁画/淡彩）先验证，实验性风格（皮影）后置 |
