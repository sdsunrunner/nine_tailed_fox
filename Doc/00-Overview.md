## 0. 项目宗旨（2026-08-31 定版）

**专注《故事新编》**：九尾狐特化为鲁迅《故事新编》项目支持——**不做其他短剧**，视觉手册只保留 8 篇概念图定稿风格（每篇一个视觉手册），每篇独立成片。

**成片形态**：每篇为 **10-30 分钟**的完整短片，对标《爱·死亡·机器人》——单篇独立、风格鲜明（8 篇 8 种美术风格）、制作精良、成片完整。

- **分集仅技术切割**：MiniMax H3 导演台单次视频时长有限，成片按技术上限切段生产（每段 ≤5 分钟），切割点落在场景/镜头自然边界，非编剧结构
- **质量标准**：院线电影级剧本（整片三幕/人物弧光/视听化写作/整片节奏）、导演美学统一、跨镜资产一致性
- **视觉体系**：8 篇视觉手册（蒋兆和写实水墨/汉画像石/白描枯山水/敦煌重彩/枯山水淡彩/水墨草书版刻/宣纸淡墨/皮影戏台）+ 影视视觉语言总纲

**路线图**：
- **短期（进行中）**：完成《铸剑》短片（鲁迅《故事新编》同名篇目）
- **中长期**：完成《故事新编》全部 8 篇的短片化——每篇一个独立成片、每篇一种鲜明美术风格，详见 [10-Story-New-Compilation-Roadmap.md](./10-Story-New-Compilation-Roadmap.md)

## 1. 项目简介

**nine_tailed_fox**（九尾狐）是《故事新编》**全流程一站式生产工作台**。
它将《故事新编》各篇从「剧本创意」到「音视频素材产出」的全链路集成到一个工作台中，
通过 AI 能力深度辅助创作与生成，让单个创作者也能高效完成 8 篇精品短片的完整生产。

## 2. 产品定位

| 维度 | 定位 |
|------|------|
| 一句话定位 | 《故事新编》精品短片全流程一站式 AI 生产工作台（对标《爱·死亡·机器人》） |
| 目标用户 | 短片创作者、独立制作人（专用于《故事新编》篇目） |
| 核心价值 | 全链路打通 + AI 深度辅助 + 单人可独立完成 + 8 篇风格差异化 + 院线级成片质量 |
| 协作模式 | 单人优先（后续可扩展协作） |
| 部署形态 | 混合架构（Web + 本地 Agent） |

## 3. 流程范围

### 3.1 包含的核心环节

```
选题灵感 → 剧本创作 → 分镜与可视化 → 音视频生成 → 素材入库
```

| 环节 | 说明 |
|------|------|
| 选题灵感 | AI 辅助选题、题材库、热门趋势 |
| 剧本创作 | 大纲 → 分集 → 分场剧本，对白与动作描述 |
| 分镜与可视化 | 剧本拆镜、镜头设计、角色/场景设定、故事板 |
| 音视频生成 | 按镜头生成视频片段、TTS 配音、配乐与音效 |
| 素材入库 | 生成物统一管理、版本化、可供下游使用 |

### 3.2 暂不包含（本期范围外）

- **剪辑与成片**：片段拼接、转场、字幕、最终成片导出（预留素材导出接口，供下游剪辑工具使用）

> 设计上预留成片环节的对接能力，生成素材以标准格式入库，可导出至第三方剪辑工具。

## 4. 核心术语表

| 术语 | 英文 | 定义 |
|------|------|------|
| 剧目 | Project | 一部精品短片的顶层容器（对标《爱死机》单篇），包含全部创作资产 |
| 分集 | Episode | 成片按 MiniMax H3 技术上限的切段（每段 ≤5 分钟），非编剧结构，不设每集钩子 |
| 分场 | Scene | 一段内的一个场景段落，由时间地点界定 |
| 分镜 | Shot / Storyboard | 分场拆解出的单个镜头单元，是音视频生成的基本单位 |
| 镜头 | Shot | 一个分镜对应的视觉画面描述（景别/角度/运镜/时长） |
| 视觉设定 | Visual Asset | 角色卡、场景卡、道具卡等设定资产 |
| 故事板 | Storyboard | 分镜的可视化呈现（分镜图） |
| 素材 | Asset | 所有生成物的统称（图/视频/音频/文本） |
| Provider | AI Provider | AI 能力提供方（云端 API 或本地 ComfyUI） |

## 5. 设计原则

1. **全链路贯通** — 从剧本到素材，数据在环节间自然流转，避免割裂
2. **AI 原生** — AI 不是外挂工具，而是嵌入每个环节的原生能力
3. **人机协同** — AI 生成 + 人工精修，始终保留人工干预与编辑能力
4. **本地算力优先** — 图像/视频生成专注于本地部署的 ComfyUI，云端 API 仅作备选，兼顾成本/质量/隐私
5. **渐进增强** — 单人优先 → 协作扩展；MVP → 完整能力
6. **素材可复用** — 视觉设定、生成素材跨镜头/跨集复用，保证一致性

## 6. 技术栈概要

| 层 | 技术选型 | 说明 |
|----|----------|------|
| Web 前端 | **Vue 3 + Vite**（Element Plus） | 浏览器访问，编辑/管理/预览（Web 形式展示） |
| 云端服务 | Node.js（Express 5）+ Python（FastAPI + LangChain） | 业务逻辑、AI 编排、存储；LangChain 独立 AI 服务 |
| 记忆/向量库 | **Milvus** | 素材语义检索、角色一致性召回、项目记忆 |
| 本地 Agent | 本地任务执行器 + **ComfyUI** | 图像/视频生成（本地算力为主） |
| AI 能力层 | Provider 抽象 | 本地 ComfyUI 为主 + 云端 API 备选 |
| 部署 | **Docker Compose 全栈** | 前端/后端/AI/DB/队列/Milvus/ComfyUI 统一编排 |

详见 [02-Architecture.md](./02-Architecture.md)。
