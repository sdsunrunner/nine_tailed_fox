# 新建视觉手册 · 编写规则与标准模板

## 一、视觉手册的定位

视觉手册＝**静态资产画风手册**：为「角色卡 / 场景卡 / 道具卡 / 分镜首帧图」的生图提示词定义统一画风。不管动态内容（小说改剧本/镜头/节奏由导演手册负责），不管角色演出（微表情表演技能负责）。

## 二、编写规则（五步）

1. **定参考系**：从真实影视/动画作品出发（如「90年代武侠电影」→《东方不败》《新龙门客栈》；「吉卜力」→《千与千寻》《龙猫》），用一句话定位质感方向。
2. **总结色彩与调色**：主色板、饱和度/对比度倾向、冷暖对冲关系、题材色彩惯例。
3. **总结光影与质感**：光型（自然光/逆光剪影/高反差/柔光…）、材质与胶片/颗粒/景深参数。
4. **总结构图与镜头语言**：构图惯例（对称/留白/对角线/框式…）、景别节奏、标志性环境元素。
5. **写生图提示词根**：可直接被文生图模型执行的段落（写清光型+色板+质感+景别+构图词）。

## 四、硬性要求

- 必须包含 frontmatter（name / displayName / description / metaData）与全部 7 个段落，段落顺序固定。
- 「生图提示词根」必须具体可执行（写明光型/色板/质感/景别/构图词），禁止「高质量/真实感/氛围好」等空话。
- 职责边界段落照抄标准句，不得改动。
- name 用英文小写+下划线（字母数字_-）；displayName 用中文；description 以「视觉手册·」开头。
