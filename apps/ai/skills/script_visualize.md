# 剧本视觉化改写（Show Don't Tell）

把抽象情绪翻译为可拍摄的动作和画面，让观众通过**看到的画面**感受情绪，而不是被告知情绪。九尾狐剧本→分镜/视频生成前必须过此关：分镜图和 videoDesc 只能拍"可拍的动作"，拍不了"她很伤心"。

## 核心原则

**第一性原则**：用动作和画面提升情绪，而不是模糊的情绪形容词。

- **可拍性**：不可拍的信息不进入分镜（"伤心"不可拍，"咬唇+眼眶泛红+转身离开"可拍）
- **具体化**：每个动作具体明确（❌ 她很紧张 → ✅ 她不停地搓着手）
- **可拍化**：动作能被摄影机捕捉（❌ 内心矛盾 → ✅ 手伸向门把手又缩回，反复三次）
- **情绪化**：动作传达情绪（❌ 她走了 → ✅ 她转身快步离开，没有回头）

## 一、情绪形容词黑名单

以下情绪形容词**禁止直接出现在剧本/分镜描述**中，必须翻译为动作或画面：

**基础情绪类**：伤心、难过、悲伤、痛苦、心碎；开心、高兴、快乐、兴奋、激动；愤怒、生气、恼火、暴怒、愤恨；害怕、恐惧、惊恐、紧张、不安；惊讶、震惊、意外、诧异、惊愕

**复杂情绪类**：失望、绝望、无助、无奈、迷茫；尴尬、羞愧、内疚、后悔、自责；嫉妒、羡慕、不甘、憋屈、委屈；冷漠、麻木、疲惫、厌倦、无聊；温柔、温暖、感动、心疼、怜惜

**状态描述类**：紧张、焦虑、慌乱、不知所措；犹豫、纠结、矛盾、挣扎、动摇；坚定、果断、决绝、冷静、淡定；疲惫、虚弱、无力、崩溃、绝望

**允许的网文感情绪词**（类型化标记，可保留但**必须配合具体动作**）：
- 冷笑、嗤笑、冷哼、轻笑、讥笑；眼神一冷、目光一沉、脸色一变；嘴角上扬、眉头一挑、眼神闪烁

## 二、动作情绪化翻译表（按情绪类型）

### 伤心/难过
| 情绪形容词 | 动作化翻译 | 画面语言 |
|-----------|-----------|---------|
| 她很伤心 | 她低头盯着手机屏幕，拇指悬在发送键上方，颤抖着，最终还是删掉了整段文字 | 特写：手指颤抖 + 删除动作 |
| 他难过极了 | 他靠在墙上，缓缓滑坐到地上，双手抱住膝盖，把脸埋进臂弯里 | 全景：滑坐动作 + 蜷缩姿态 |
| 她心碎了 | 她咬紧下唇，眼眶泛红，强忍着没让泪水落下，转身快步离开 | 中景：咬唇 + 眼眶泛红 + 转身 |

**设计原则**：具体身体动作（低头/咬唇/颤抖）；加入环境细节（手机/墙）；强调克制压抑（强忍/没让泪水落下）；避免直接流泪（太直白缺乏张力）。

### 愤怒/生气
| 情绪形容词 | 动作化翻译 | 画面语言 |
|-----------|-----------|---------|
| 他很愤怒 | 他猛地站起身，椅子被推得向后滑出一米，发出刺耳的摩擦声 | 全景：站起 + 椅子滑动 + 声音 |
| 她生气了 | 她把手中的文件重重摔在桌上，纸张散落一地，转身就走 | 中景：摔文件 + 纸张散落 + 转身 |
| 他暴怒 | 他握紧拳头，指节泛白，青筋暴起，盯着对方一字一顿："你、再、说、一、遍。" | 特写：拳头 + 指节泛白 + 青筋 |

**设计原则**：爆发性动作（站起/摔/握拳）；声音元素（摩擦声/一字一顿）；身体细节（指节泛白/青筋）；短句台词增强情绪。

### 害怕/恐惧
| 情绪形容词 | 动作化翻译 | 画面语言 |
|-----------|-----------|---------|
| 她很害怕 | 她下意识后退一步，背抵住墙，双手紧紧攥着衣角，眼神不敢直视对方 | 中景：后退 + 抵墙 + 攥衣角 |
| 他恐惧不安 | 他的手不停地颤抖，试图拿起水杯，却两次都没拿稳，水洒了一桌 | 特写：颤抖的手 + 水杯 + 洒水 |
| 她惊恐万分 | 她瞳孔骤然放大，呼吸急促，想说话却发不出声音，只能张着嘴 | 特写：瞳孔 + 呼吸 + 张嘴无声 |

**设计原则**：防御性动作（后退/抵墙/攥衣角）；失控细节（颤抖/洒水）；生理反应（瞳孔放大/呼吸急促）；避免尖叫（太直白）。

### 惊讶/震惊
| 情绪形容词 | 动作化翻译 | 画面语言 |
|-----------|-----------|---------|
| 她很惊讶 | 她手中的咖啡杯停在半空，眼睛微微睁大，盯着对方好几秒才反应过来 | 中景：杯子悬空 + 眼睛睁大 + 凝视 |
| 他震惊了 | 他正在签字的笔突然顿住，抬起头，眉头紧皱："你说什么？" | 特写：笔顿住 + 抬头 + 皱眉 |
| 他目瞪口呆 | 他愣在原地，手机从手中滑落，掉在地上，他却毫无反应 | 全景：愣住 + 手机滑落 + 无反应 |

**设计原则**：中断动作（杯子停住/笔顿住/手机滑落）；时间停滞感（好几秒/愣在原地）；欲言又止。

### 失望/绝望
| 情绪形容词 | 动作化翻译 | 画面语言 |
|-----------|-----------|---------|
| 她很失望 | 她看着对方，眼神从期待变得黯淡，最后垂下眼帘，轻声说："算了。" | 中景：眼神变化 + 垂眼 + 轻声 |
| 他绝望了 | 他无力地坐在椅子上，双手垂在身侧，目光空洞地盯着前方，一动不动 | 全景：无力坐姿 + 垂手 + 空洞目光 |
| 她心灰意冷 | 她把手中的戒指放在桌上，推向对方，起身离开，没有回头 | 中景：放戒指 + 推向对方 + 离开 |

**设计原则**：放弃性动作（垂眼/垂手/放下）；无力感（无力坐着/一动不动）；象征性物品（戒指/雨）。

### 尴尬/羞愧 / 犹豫/纠结 / 冷漠/麻木
- **尴尬/羞愧**：回避动作（躲闪/低头/转身）+ 不自然感（不自然笑/慌乱脚步）+ 生理反应（脸红/咬唇）
- **犹豫/纠结**：重复动作（反复/来回/移动）+ 停滞感（悬停/迟迟没有）+ 焦虑细节（咬笔帽/揉太阳穴）+ 叹气
- **冷漠/麻木**：机械动作（机械点头/滑屏）+ 无反应（没眨眼/没听见）+ 距离感（目光滑过/抱胸）

## 三、画面语言设计原则

### 景别选择（按情绪）
| 情绪类型 | 推荐景别 | 原因 |
|---------|---------|------|
| 细腻情绪（伤心/失望） | 特写/大特写 | 捕捉微表情和细节 |
| 爆发情绪（愤怒/惊讶） | 中景/全景 | 展现肢体动作和空间关系 |
| 压抑情绪（冷漠/麻木） | 中景 | 保持距离感，强调隔阂 |
| 复杂情绪（犹豫/纠结） | 特写+全景交替 | 内心挣扎与外部环境对比 |

### 动作设计三原则
1. **具体化**：❌ 她很紧张 → ✅ 她不停地搓着手
2. **可拍化**：❌ 她内心充满矛盾 → ✅ 她的手伸向门把手，又缩了回来
3. **情绪化**：❌ 他坐下 → ✅ 他靠在墙上，缓缓滑坐到地上

### 环境细节增强法
| 情绪 | 环境细节 | 效果 |
|-----|---------|------|
| 伤心 | 水龙头一直流着、雨声、空荡房间 | 增强孤独感 |
| 愤怒 | 椅子摩擦声、纸张散落、玻璃碎裂 | 增强爆发感 |
| 恐惧 | 昏暗灯光、阴影、寂静 | 增强压迫感 |
| 失望 | 窗外的雨、空咖啡杯、未接来电 | 增强无力感 |

### 视觉隐喻库
| 情绪/状态 | 视觉隐喻 |
|----------|---------|
| 关系破裂 | 戒指、照片、信件 |
| 时间流逝 | 钟表、日历、窗外光线变化 |
| 内心挣扎 | 镜子、倒影、阴影 |
| 希望破灭 | 熄灭的烟、凋零的花、停止的钟 |
| 压抑情绪 | 紧握的拳头、咬紧的牙、颤抖的手 |

## 四、情绪对比法与层次递进

### 情绪对比法（前后对比增强冲击）
```
※ 她盯着手机屏幕，眼睛一眨不眨，嘴角微微上扬。
△ 屏幕亮起，她立刻点开消息。
※ 看清内容后，她的笑容僵住，手指停在屏幕上。
△ 她缓缓放下手机，眼神黯淡下来。
```

### 情绪层次递进法（多层次动作展现深度）
```
第一层（表面克制）：她咬着下唇，眼眶泛红，但强忍着没让泪水落下。
第二层（身体反应）：她的手不自觉地握紧，指甲陷进掌心。
第三层（情绪爆发）：她转身快步离开，脚步越来越快。
第四层（崩溃释放）：她靠在墙上，缓缓滑坐到地上，把脸埋进臂弯里，肩膀剧烈颤抖。
```

### 留白与克制（最高级）
- ❌ 他暴怒，大声吼叫 → ✅ 他深吸一口气，闭上眼睛，再睁开时眼神冰冷："出去。"
- ❌ 她痛哭流涕 → ✅ 她咬紧下唇，眼眶泛红，强忍着没让泪水落下，转身离开

**原则**：压抑的情绪比爆发的情绪更有张力。

## 五、视觉化评分（量化指标）

| 指标 | 目标值 | 评分 |
|-----|--------|------|
| 情绪形容词密度 | ≤ 2个/1000字 | 30%（每超1个扣5分） |
| 动作描写占比 | ≥ 30% | 25%（每少5%扣5分） |
| 对话占比 | ≥ 50% | 20%（每少5%扣5分） |
| 具体动作数 | 每场戏 ≥ 3个 | 15%（每少1个扣3分） |
| 环境细节数 | 每场戏 ≥ 1个 | 10%（没有扣10分） |

**评级**：90-100优秀（PASS）/ 70-89良好（PASS建议优化）/ 50-69及格（FAIL需修改）/ <50不及格（FAIL大幅修改）

**输出**：视觉化评分报告（情绪形容词清单 + 改写建议 + 评分 + PASS/FAIL结论）

## 六、实战检查清单（改写/审核时逐项过）

- [ ] 是否有情绪形容词黑名单中的词？
- [ ] 每个情绪是否都有对应的动作或画面？
- [ ] 动作是否具体、可拍、情绪化？
- [ ] 是否使用环境细节增强情绪？
- [ ] 是否有视觉隐喻？
- [ ] 情绪形容词密度 ≤ 2个/1000字？
- [ ] 动作描写占比 ≥ 30%？
- [ ] 每场戏 ≥ 3 个具体动作 + ≥ 1 个环境细节？

## 七、与九尾狐其他技能协同

- **剧本→分镜前**：先用本技能把剧本视觉化（情绪→动作），再拆镜
- **分镜 prompt（三段式）**：画面描述必须是动作/姿态/表情/环境，禁止情绪形容词
- **videoDesc（H3 Ref2VA）**：detailed_description 中情绪按可见动作过程写（刺激抵达→本能反应→压制→身体泄露→选择→余波），与微表情表演规范叠加
