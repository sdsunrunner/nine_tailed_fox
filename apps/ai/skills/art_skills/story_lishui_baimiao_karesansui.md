# 理水 · 白描枯山水 · 视觉手册

## 视觉定位（参考系）

**重白描 × 枯山水淡彩融合**（宋人小品质感）：主体用白描细线清晰勾勒（官僚衣纹/帽翅/五官、民夫身形/堤坝结构），背景枯山水淡彩（苍白米色底、枯枝孤影、极简留白）——白描的辛辣讽刺 + 枯山水的克制寂寥。

## 色彩与调色

- 主色板：墨线（白描）/ 苍白米色底 / 枯灰山石；极少量点缀色（朱批红、一点青绿）。
- 极简淡彩：米白为主、留白面积大、低对比。

## 光影与质感

- 无强烈光影（白描平面感 + 枯山水疏淡）。
- 宣纸纹理、细线工笔质感；枯枝孤影、微尘微雪。

## 构图与镜头语言

- 白描细线为主体：群像（大肚官、小吏簇拥）、水利工地大场面。
- 枯山水留白构图：极简、大量空白；俯视大场面（治水工地 vs 官厅）。
- 官场讽刺的荒诞 + 枯寂的克制并存。

## 生图提示词根

```

墨线为主体、淡彩为底，官场讽刺辛辣与枯寂克制并存，
群像（大腹便便官僚围案指手画脚），水利工地大场面俯视
```

## 严禁内容

- 现代元素、卡通、油画质感。
- 过度浓墨重彩（保持白描为主、淡彩为辅）；放弃写实光影立体感。

> **职责边界（本手册＝静态资产）**：本手册仅用于**静态资产生成**——角色卡/场景卡/道具卡/分镜首帧图的生图提示词；**动态内容**由项目**导演手册**负责；与导演风格根冲突时，静态画风以本手册为准。
