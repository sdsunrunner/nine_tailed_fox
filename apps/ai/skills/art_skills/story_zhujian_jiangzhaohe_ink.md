# 铸剑 · 蒋兆和写实水墨 · 视觉手册

## 视觉定位（参考系）

参考蒋兆和《流民图》系写实水墨人物画 + 宋元水墨：**写实造型严谨 + 中锋用笔 + 皴擦渲染 + 墨色干湿浓淡层次丰富**，悲悯厚重、底层苦难中的尊严。青灰冷调、褪色旧照片、阴天散射光。楚国（春秋）设定，写实古风。

## 色彩与调色

- 主色板：青灰 / 墨黑 / 一点血红（血与火、剑穗）；低饱和、去艳色。
- 水墨灰阶层次丰富（墨分五色）：浓墨轮廓、淡墨渲染、飞白枯笔。
- 褪色旧照片颗粒感；金褐暖光（室内王宫）与青灰冷调（外景）对比。

## 光影与质感

- 阴天散射自然光、窗光、烛火油灯光；拒绝舞台式打光。
- 水墨皴擦质感（衣纹/山石/器物）、宣纸纹理、胶片颗粒。
- 古旧器物真实磨损（青铜鼎、粗布、剑）；悲怆厚重的历史感。

## 构图与镜头语言

- 人物居画面三分之一，大面积留白；框式构图（门/窗/廊柱前景框）。
- 深焦前后景清晰；大远景山水（人物小环境大）。
- 写实人物 + 水墨笔墨并存：结构写实、笔墨写意。

## 生图提示词根

```
蒋兆和写实水墨人物画风格（流民图质感），楚国春秋写实古风，
写实造型严谨，中锋用笔勾勒，皴擦渲染衣纹，墨色干湿浓淡层次丰富，
青灰冷调+墨黑+一点血红（血与火），低饱和褪色旧照片颗粒，
阴天散射光，悲悯厚重、底层苦难中的尊严，
人物居三分之一+大面积留白，框式构图，深焦，
青铜鼎/粗布/古剑的磨损质感，水墨为魂、民生为骨
```

## 高潮段（鼎中大战）写意水墨提示词根

```
写意水墨，狂放泼墨，虚幻空间，无鼎无头，
三个完整人形虚影（少年/君王/黑衣义士）在墨色漩涡中缠斗，
半透明如水中倒影，狂放水墨线条勾勒，飞白枯笔横扫，
青灰冷调墨黑为主，一点血红（血痕如墨中朱砂），
虚境缥缈悲壮，由实向虚的水墨幻境
```

## 严禁内容

- 现代都市/科幻/赛博元素；卡通动漫二次元。
- 高饱和荧光乱色、影楼打光；过度精致。
- 鼎中大战不得出现真实鼎器或头颅（用完整人形虚影 + 写意墨线表现）。

## 职责边界

> **职责边界（本手册＝静态资产）**：本手册仅用于**静态资产生成**——角色卡/场景卡/道具卡/分镜首帧图的生图提示词；**动态内容**（小说改剧本、分镜划分、镜头语言、运镜、节奏、视频提示词）由项目**导演手册**负责；与导演风格根冲突时，静态画风以本手册为准。
