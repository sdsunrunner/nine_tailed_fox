# 采薇 · 枯山水淡彩 · 视觉手册

## 视觉定位（参考系）

参考枯山水庭园 + 宋人山水小品：**苍白米色底、枯枝孤影、微雪/微尘**；「采薇」的野菜青绿作唯一生色；极简构图、大量留白。安静到残酷的气节悲剧。

## 色彩与调色

- 主色板：苍白米白底 / 枯灰 / 一点青绿（野菜、新生）。
- 极淡彩、低饱和；留白面积占画面主体。

## 光影与质感

- 无强烈光影（疏淡平面感）；宣纸/绢本质感。
- 枯枝纹理、微雪飘落、风与枯叶；极简主义。

## 构图与镜头语言

- 极简构图、大面积留白；人物渺小（两位隐士拄杖/采薇）。
- 枯山孤景、寒雾；安静、克制、有尊严。

## 生图提示词根

```
枯山水淡彩水墨风格，宋人小品质感，
两位瘦骨嶙峋的隐士伯夷叔齐，褪色麻衣拄杖立于枯树下，
苍白米色底、枯枝孤影、微雪飘落，野菜青绿作唯一生色，
极简构图、大量留白，克制哀伤有尊严，
首阳山枯寂山景：孤山枯树寒雾，天地间微小身影
```

## 严禁内容

- 浓墨重彩、写实电影感、卡通。
- 高饱和色（除唯一青绿生色）；复杂构图（须极简留白）。

## 职责边界

> **职责边界（本手册＝静态资产）**：本手册仅用于**静态资产生成**——角色卡/场景卡/道具卡/分镜首帧图的生图提示词；**动态内容**由项目**导演手册**负责；与导演风格根冲突时，静态画风以本手册为准。
