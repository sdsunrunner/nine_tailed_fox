# 起死 · 皮影戏台 · 视觉手册

## 视觉定位（参考系）

参考中国皮影戏/剪纸戏台：**高饱和彩纸色块（红/黄/绿/黑）+ 镂空剪影 + 戏台幕布质感**，明显「表演感」（角色像皮影般偶动）。庄子与骷髅同框的荒诞拼贴、黑色幽默。

## 色彩与调色

- 主色板：高饱和彩纸色块——红 / 黄 / 绿 / 黑；戏台红幕。
- 鲜明、装饰感、民俗感；剪纸镂空的纯色块。

## 光影与质感

- 皮影平面感（无写实光影）；镂空剪影、纸片质感、幕布纹理。
- 角色偶动（皮影关节感）；锣鼓喧天的戏台氛围。

## 构图与镜头语言

- 戏台红幕、镂空剪纸山石树木；庄子与骷髅相对辩难。
- 快节奏嘴仗的表演感；荒诞、戏谑、闹剧。

## 生图提示词根

```
皮影戏剪纸风格，戏台幕布质感，
庄子与一具起死回生的骷髅相对而立（骷髅正活动肢体），
高饱和彩纸色块（红黄绿黑）、镂空剪影、皮影偶动，
戏台红幕、镂空剪纸山石树木，明显表演感，
荒诞戏谑、黑色幽默、锣鼓喧天
```

## 严禁内容

- 写实电影感、水墨写意、卡通 CG。
- 低饱和灰调（须保持皮影高饱和彩纸色块）。

## 职责边界

> **职责边界（本手册＝静态资产）**：本手册仅用于**静态资产生成**——角色卡/场景卡/道具卡/分镜首帧图的生图提示词；**动态内容**由项目**导演手册**负责；与导演风格根冲突时，静态画风以本手册为准。
