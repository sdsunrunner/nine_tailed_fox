# 奔月 · 汉画像石拓片 · 视觉手册

## 视觉定位（参考系）

参考汉代武梁祠画像石/画像砖（后羿射日、嫦娥奔月为经典母题）：**石刻线刻剪影 + 拓片质感**，赭红拓片底、墨黑线刻、岩灰肌理、分格叙事构图。中国最早神话叙事艺术的原始粗犷。

## 色彩与调色

- 主色板：赭红（拓片底）/ 墨黑（线刻）/ 岩灰（石面肌理）。
- 低饱和、古朴沉着；拓片斑驳纹理、岁月痕迹。
- 可有一丝暗金（射日余晖的暗示），但不喧宾夺主。

## 光影与质感

- 平面石刻感：线刻剪影、阴刻/阳刻纹理、拓片墨迹晕染。
- 斑驳风化肌理、石刻刀痕；无写实光影（平光拓片感）。

## 构图与镜头语言

- 画像石分格叙事构图（一格一景）；人物侧面剪影、程式化造型。
- 车马仪仗分层排列、神话场景（九日、弯弓、奔月）。
- 粗犷朴拙的原始史诗感。

## 生图提示词根

```
汉代画像石拓片风格（武梁祠画像石质感），后羿射日神话母题，
石刻线刻剪影，赭红拓片底色+墨黑线刻+岩灰肌理，
分格叙事构图（一格一景），车马仪仗分层排列，
拓片斑驳纹理、岁月痕迹，粗犷朴拙，
人物侧面程式化剪影（弯弓/奔月），原始史诗感
```

## 严禁内容

- 现代元素、彩色插画、油画质感、卡通。
- 过度写实的三维立体感（保持平面石刻拓片感）。

## 职责边界

> **职责边界（本手册＝静态资产）**：本手册仅用于**静态资产生成**——角色卡/场景卡/道具卡/分镜首帧图的生图提示词；**动态内容**由项目**导演手册**负责；与导演风格根冲突时，静态画风以本手册为准。
