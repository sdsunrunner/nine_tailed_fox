# 补天 · 敦煌壁画重彩 · 视觉手册

## 视觉定位（参考系）

参考敦煌莫高窟壁画（882 敦煌 LoRA 强化）：**重彩矿物色 + 飞天飘带线条 + 壁画剥落质感**。金/赭/朱/青金石蓝的高饱和矿物色，创世混沌（星云/海）用大色块流动，女娲抟土补天的壮丽与荒诞。

## 色彩与调色

- 主色板：金 / 赭 / 朱 / 青金石蓝（高饱和矿物色）；石绿点缀。
- 壁画斑驳剥落质感、金箔剥蚀；创世混沌用流动大色块。

## 光影与质感

- 壁画平面感（无写实光影）；矿物颜料厚重、颗粒感。
- 飞天飘带线条、衣纹如壁画勾勒；剥落/龟裂肌理。

## 构图与镜头语言

- 对称仪式构图、大远景巨神（女娲顶天立地）、天地分层的创世场面。
- 五色石在天空流转、云海翻涌；庄严、宏大、神圣。

## 生图提示词根

```
敦煌壁画重彩风格，888 Dunhuang 质感，女娲补天创世神话，
金赭朱青金石蓝高饱和矿物色，飞天飘带线条，
壁画剥落质感，对称仪式构图，大远景巨神顶天立地，
五色石流转天空，云海翻涌，壮丽神圣荒诞
```

## 严禁内容

- 现代元素、写实电影感、卡通。
- 低饱和灰调（须保持敦煌重彩的高饱和矿物色）。

## 职责边界

> **职责边界（本手册＝静态资产）**：本手册仅用于**静态资产生成**——角色卡/场景卡/道具卡/分镜首帧图的生图提示词；**动态内容**由项目**导演手册**负责；与导演风格根冲突时，静态画风以本手册为准。
