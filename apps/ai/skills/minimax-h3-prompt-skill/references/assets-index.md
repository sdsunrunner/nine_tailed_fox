# 素材库索引

案例引用的参考素材来自 GPT-Image2 图库（`awesome-gpt-image-2-main/generated-images`），按用途分类。使用前将素材文件复制到 ComfyUI 输入目录，或作为 R2V 参考传入。

## 分类与用途

| 分类 | 内容 | H3 用途 |
|------|------|---------|
| `brand-poster/` | 高端香水、科技发布会、腕表、新能源汽车品牌海报 | I2V 动态海报、R2V 品牌风格参考 |
| `character-concept/` | 赛博朋克女战士、仙侠剑客、蒸汽机械师、暗黑圣骑士 | T2V 风格方向、R2V 角色参考 |
| `character-sheet/` | 角色三视图（战士/剑客/机械师/骑士） | I2V 首帧、R2V 身份锁定 |
| `event-poster/` | 科技峰会、艺术展、音乐节、美食节海报 | I2V 现场感动态、T2V 场景方向 |
| `product-concept/` | 智能手机、手表、耳机、家居中枢 | I2V 产品动态化、R2V 产品宣传片 |
| `ui-design/` | 电商/音乐/社交/健身 APP 界面 | R2V UI 交互动效 |
| `wechat-cover/` | 科技/财经/生活方式/旅行配图 | T2V 内容方向、I2V 封面动态化 |
