# 词汇表：景别 / 镜头运动 / 轴线 / 灯光 / 立体声

## 景别（Shot Size）

| 术语 | 中文 | 用途 |
|------|------|------|
| Extreme Wide / Establishing | 大远景 / 定场 | 交代环境、尺度 |
| Wide / Long | 远景 | 人物与环境关系 |
| Full | 全景 | 完整动作，建立空间 |
| Medium | 中景 | 对话、动作主体 |
| Close-Up | 近景 | 情绪、细节 |
| Extreme Close-Up | 特写 / 大特写 | 强调、符号、关键时刻 |

规则：远→近是聚焦，近→远是揭示；景别反差 = 剪辑冲击。

## 镜头运动

| 术语 | 中文 | 动机 |
|------|------|------|
| Dolly in / Push-in | 推 | 逼近、聚焦、心理压迫 |
| Pull back | 拉 | 揭示环境、疏离、收尾 |
| Pan | 摇 | 扫视关系、追踪方向 |
| Track / Follow | 移 / 跟 | 跟随运动主体 |
| Crane / Jib | 升降 | 建立镜头、改变视角与权力 |
| Handheld | 手持 | 不安、纪实、紧张 |
| Locked-off / Tripod | 固定 | 稳定、压抑、仪式感 |
| Steadicam / Gimbal | 斯坦尼康 | 边走边谈、跟拍、沉浸 |
| Whip pan | 甩镜头 | 能量、转场、动作衔接 |
| Dolly zoom / Hitchcock zoom | 滑动变焦 | 悬疑、揭示、心理时刻 |
| Rack focus | 焦点转移 | 引导注意、情绪转变 |
| Slow orbital arc | 环绕轨道 | 产品展示、环绕揭示 |
| Dutch angle | 斜角镜头 | 不安、紧张、迷失 |

规则：一条视频只选 1-2 种运镜语言用到底，风格统一。

## 轴线与衔接

| 术语 | 含义 |
|------|------|
| 180° rule | 机位守在两人连线同一侧，画面左右关系不翻转 |
| Match cut | 用相似构图 / 形状 / 运动接两镜 |
| Action continuity | 在动作进行中切换，隐藏剪辑点 |
| J-cut | 声音先入：下一镜头声音先于画面进入 |
| L-cut | 画面先入：画面先切，声音留在上一镜 |
| Shot / reverse shot | 正反打：对话双方各占画面一侧交替 |
| Establishing shot | 定场：开场交代环境的大景别 |

## 情绪弧线词

- build（积累）/ release（释放）/ afterglow（余韵）
- tension（张力）/ stinger（突袭音）/ silence drop（静音呼吸）
- BGM 按弧线描述：`calm → uneasy → burst → afterglow`，别写"配乐"

## 灯光

Golden hour、Blue hour、Rembrandt lighting（伦勃朗光）、Butterfly lighting、Split lighting、Rim light / Backlight（轮廓光）、Chiaroscuro（明暗对照）、Neon noir（赛博朋克霓虹）、God rays / Crepuscular（体积光）。

规则：光源方向 / 色温在总览里定义一次，后续引用，别逐镜乱改。
