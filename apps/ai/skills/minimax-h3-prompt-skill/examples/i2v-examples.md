# I2V 图生案例

首帧/尾帧直接接资产库里的图，提示词描述两帧之间的运动。素材路径见 `references/assets-index.md`。

## 案例 1：角色三视图 → 角色入场

首帧：`character-sheet/001-赛博战士三视图`（静态立绘）

```
Use the first frame as the sole identity reference. The character turns
from three-quarter view to face camera, takes two steps forward.

0-4s: slight breathing idle, cape sways.
4-9s: she steps forward, camera pushes in from waist to shoulders.
9-12s: stops, glances up, rim light flashes across the armor.

Footsteps on metal floor with echo. Armor plating clicks.
Low bass hum, a single synthesized chord resolves at the end.
Keep face, armor, and color palette exactly as in the first frame.
```

## 案例 2：品牌海报 → 动态海报

首帧：`brand-poster/001-高端香水品牌海报` 或 `003-高端腕表品牌海报`

```
Animate the poster: elements come alive while keeping the layout intact.

0-4s: background particles drift in, product stays anchored center.
4-8s: the product rotates slowly, headline text fades in bottom-third.
8-12s: light sweep crosses the frame, sparkle accents settle.

Soft ambient pad, gentle whoosh on each element entrance.
Keep title, brand text, and product shape pixel-consistent.
```

## 案例 3：产品概念图 → 动态展示

首帧：`product-concept/001-概念智能手机` 或 `002-概念智能手表`

```
The product from the first frame rotates on a seamless studio surface,
interface elements glowing softly.

0-5s: slow 360° orbit, edge highlights sweep across the body.
5-10s: macro push into the screen, UI icons float and re-arrange.
10-12s: camera pulls back, product settles center, breathing glow.

Clean UI feedback ticks, soft whoosh on orbit, subtle digital pad.
Keep product silhouette and screen UI exactly as designed.
```

## 案例 4：活动海报 → 现场感动态

首帧：`event-poster/001-科技峰会海报` 或 `003-音乐节海报`

```
Turn the static poster into a living scene of the event.

0-5s: the stage lights up, crowd silhouettes appear, banner text shines.
5-10s: camera pans across the venue, light beams sweep the audience.
10-12s: lock on center stage, confetti falls, energy peaks.

Crowd roar swells, music kicks in at 5s, bass-heavy.
Keep event name and date text legible and unchanged.
```
