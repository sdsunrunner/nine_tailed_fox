# 分镜画面描述要素（Frame Description Element Checklist）

生成任何**静态画面描述**（分镜 prompt、分镜首帧图、角色/场景/道具资产图）时，按此清单检查要素完整性。确保描述信息完整、可直接用于文生图/图生视频，不依赖模型"脑补"。

## 一、26 项要素清单（按类别）

### A. 镜头六要素（Camera Core）
| # | 元素 | 可选值示例 |
|---|------|-----------|
| 1 | **景别** | 远景 / 全景 / 中景 / 近景 / 特写 / 大特写 / 极特写 |
| 2 | **镜头运动**（静态图标"固定"） | 推 / 拉 / 摇 / 移 / 跟 / 升降 / 固定 |
| 3 | **方位构图** | 中央构图 / 三分法 / 对称 / 对角线 / 框架构图 |
| 4 | **机位角度** | 平视 / 俯拍 / 仰拍 / 荷兰角（倾斜） |
| 5 | **光线类型** | 顶光 / 侧光 / 逆光 / 底光 / 硬光 / 柔光 |
| 6 | **氛围情绪** | 紧张 / 温馨 / 压抑 / 明快 / 诡异 / 孤独 / 释然 |

### B. 人物描述（Character）
| # | 元素 | 可选值示例 |
|---|------|-----------|
| 7 | **人物位置** | 左三分线 / 中央 / 右侧 / 画面底部 / 边缘 |
| 8 | **人物朝向** | 正面 / 四分之三侧面 / 侧面 / 背面 + 视线方向 |
| 9 | **姿态动作** | 站立 / 坐姿 / 蹲下 / 前倾 / 伸手触碰 / 回头 |
| 10 | **表情眼神** | 眉头微蹙、眼神专注 / 眼睛睁大、嘴唇微张 / 目光低垂 |
| 11 | **人物关系**（多人） | 对峙 / 并排 / 前后 / 围绕 / 背对背 |

### C. 空间层次（Spatial Depth）
| # | 元素 | 可选值示例 |
|---|------|-----------|
| 12 | **前景元素** | 前景镜框 / 虚化植物 / 前景烟雾 / 无 |
| 13 | **中景主体** | 主要活动区域内容 |
| 14 | **背景环境** | 背景空间描述（虚焦/延伸/黑暗） |
| 15 | **景深效果** | 浅景深 / 中景深 / 深景深 |

### D. 光影色彩（Light & Color）
| # | 元素 | 可选值示例 |
|---|------|-----------|
| 16 | **光源方向** | 从左侧 / 从顶部 / 从背后 / 从右下方 |
| 17 | **光影效果** | 脸颊高光 / 地面长影 / 轮廓光勾勒 |
| 18 | **色温** | 冷白 5500K / 琥珀暖光 3200K / 混合色温 |
| 19 | **色调对比** | 冷蓝灰调 / 暖橙调 / 低饱和 / 高对比 |

### E. 技术风格（Technical & Style）
| # | 元素 | 可选值示例 |
|---|------|-----------|
| 20 | **焦距镜头** | 广角 24mm / 标准 50mm / 长焦 85mm |
| 21 | **画幅比例** | 16:9 / 21:9 / 9:16 / 4:3 |
| 22 | **质感风格** | 胶片颗粒 / 超写实 / 电影感 / 水墨 |

### F. 相对位置关系（Relative Positioning）
| # | 元素 | 可选值示例 |
|---|------|-----------|
| 23 | **人物与环境距离** | 距镜面约 30cm / 站在空间中央 |
| 24 | **人物与人物关系** | 两人相距约 2 米 / 面对面 / 视线交汇 |
| 25 | **物品与空间关系** | 道具在空间中的位置和比例 |
| 26 | **视觉引导线** | 视线/构图/纵深引导线 |

## 二、必备 vs 可选（按场景类型分级）

### 所有画面必备（7 项）
**景别、机位角度、方位构图、光线类型、人物位置、人物朝向、姿态动作**

### 近景/特写额外必备（+3 项）
**表情眼神、光源方向、光影效果**（面部光影精确）

### 多人场景额外必备（+2 项）
**人物关系、人物与人物关系**（距离和视线交汇）

### 全景/远景额外必备（+4 项）
**前景元素、背景环境、景深效果、人物与环境距离**

### 始终推荐（提升质量）
**色温、色调对比、画幅比例、质感风格**

## 三、相对位置描述规范

### 人物与环境
- **距离**："距镜面约 30cm" / "站在空间中央" / "靠近窗边"
- **层次**："前景镜框，中景人物，背景庭院"
- **包围**："置身于开阔空间"

### 人物与人物
- **距离**："两人相距约 2 米" / "面对面站立"
- **视线**："两人视线交汇于中央" / "各自看向不同方向"

### 物品与空间
- **位置**："剑置于桌面中央" / "水瓮在屋角暗处"
- **比例**："巨大鼎器占据画面 2/3" / "微物仅占画面 1/10"

## 四、画面描述示例（完整覆盖）

> 以角色卡为参考的中景画面。平视，四分之三侧角度。人物站在窗边，身体略微前倾，右手伸向窗棂。面部朝向窗外，眼神专注，眉头微蹙。冷白光从左侧照来，在右侧脸颊形成柔和高光。中央构图，浅景深，背景庭院虚焦。前景：无；中景：人物与窗；背景：庭院（虚焦）。人物距窗约 30cm。低饱和冷蓝灰调，色温冷白 5500K，轻微胶片颗粒，16:9 画幅。

**要素覆盖**：景别✓ 机位角度✓ 构图✓ 光线✓ 人物位置✓ 朝向✓ 姿态✓ 表情✓ 光源方向✓ 光影效果✓ 前中背景✓ 景深✓ 色温✓ 色调✓ 画幅✓ 质感✓ 人物与环境距离✓ — 共 17/26（中景单人完整覆盖）

## 五、与九尾狐其他技能协同

- **分镜 prompt（三段式【画面】）**：必须含 7 项必备要素，近景/远景按类型补额外项
- **角色/场景/道具资产图**：角色=正面全身+纯色底；场景=环境主视图；道具=静物——同样按此清单补足光线/构图/质感
- **videoDesc 的 detailed_description**：画面描述部分参照此清单保证可拍性
