# 新建导演手册 · 编写规则与标准模板（完整版）

## 〇、质量基准（先读再写）

新建导演手册前，**必须阅读以下两个完整版手册作为结构与质量基准**（两者均已按十六章节骨架落地）：

- `story_skills/Director_HouHsiaoHsien.md` —— 静观写实系基准（长镜头/空镜留白/远观/深焦框式/气韵剪辑/自然光/水墨/声音写实/风与自然/反戏剧化/日常细节/场面调度，684 行）
- `story_skills/Director_AngLee.md` —— 情感写实系基准（克制真实/家庭饭桌/压抑释放/双人同框/跨文化/伦勃朗光/色彩锚定/声音留白/细节写实/写意武侠/辽阔自然/技术实验，十六章节）

新手册必须达到同等完整度：**目录章节数 ≥ 10、正文 300-420 行（约 8000-10500 字符）、每条技法可落成提示词**。
注意：生成模型实际输出上限约 8000 tokens，必须精炼——每章节核心法则 1-2 句 + 执行参数表/清单 + 1-2 案例，禁止冗长散文；**完整性优先级高于篇幅**：宁可压缩章节内容，也必须输出完整结尾（十六章节全部到齐 + 参考文献 + 职责边界两句），绝不允许中途截断。

## 一、导演手册的定位

导演手册＝**动态内容控制手册 + 默认画风来源**：为「小说改剧本的叙事结构、分镜拆解的镜头划分、镜头语言与运镜、节奏与情绪、视频提示词」定义导演方向；同时提供「导演专属电影美学」——**项目未选视觉手册时，静态资产（角色/场景/道具/分镜首帧）的画风默认由导演美学控制**。角色演出由微表情表演技能负责。

## 二、编写规则（六步）

1. **定参考系**：从真实导演及其代表作出发（如「李安」→《饮食男女》《卧虎藏龙》《断背山》《色戒》），用一句话定位导演方向（美学来源+核心追求）。
2. **总结导演专属电影美学（新增必填）**：给出手册的 `aesthetic`（美学名称，如「李安电影美学」）与静态画面控制（色彩/光影/构图/质感/人物/背景——**每条都能落成生图提示词**）。
3. **总结叙事手法**：核心叙事结构（快节奏冲突/散点留白/多线并行/压抑释放…）+ 短剧适配要点。
4. **总结视听语言**：构图、运镜、色彩光影、剪辑声音四方面；并写「风格提示词根」——定位为**镜头语言与画面氛围方向**（不写静态画风词汇）。
5. **总结分镜表手法**：镜头序列、景别节奏、镜间衔接、分镜表特征、短剧应用。
6. **展开十六章节完整版**（新增，质量基准）：按下方第七章骨架，结合该导演真实风格，写出完整版（含：概述/核心法则/执行参数/标志性案例/逐部代表作视觉参数/与大师差异表/实操检查清单/核心片单/导演自述/参考文献）。

## 五、硬性要求

- 必须包含 frontmatter（name / displayName / description / **aesthetic** / metaData）与五段（**导演专属电影美学 / 代表作视觉 DNA / 叙事手法 / 视听语言 / 分镜表手法**），顺序固定。
- 必须展开为十六章节完整版（**目录章节数 ≥ 10、正文 300-420 行 / 约 8000-10500 字符**），结构与深度对齐 `Director_HouHsiaoHsien.md` / `Director_AngLee.md`。
- **完整性铁律**：十六章节全部到齐 + 文末 参考文献 + 职责边界两句，绝不允许截断；篇幅紧张时压缩各章节次要案例，不省略章节与结尾。
- `aesthetic` 即「导演专属电影美学」的美学名称（如 `李安电影美学`），用于视觉手册下拉的默认显示与画风回退。
- 「导演专属电影美学」章节负责**静态画面控制**（色彩/光影/构图/质感/材质/人物/背景，每条可落画面）；「风格提示词根」负责**动态镜头语言与画面氛围**，两者职责分离。
- 「代表作视觉 DNA」必须含**共性 DNA**（跨作品稳定规律）与**逐部代表作视觉参数**（每部含 → 转提示词）与**提示词速查**。
- 十六章节正文禁止空洞口号：每条技法必须给出**可执行参数**（景别/光比/时长/构图比例）或**标志性案例**（具体影片+场景）。
- 文件末尾追加以下两句（照抄，不得改动）：

```
> **职责边界（本手册＝动态内容控制 + 默认画风）**：本手册用于小说改剧本的叙事结构、分镜拆解的镜头划分、镜头语言与运镜、节奏与情绪、视频提示词等**动态内容**；**静态资产**（角色卡/场景卡/道具卡/分镜首帧图）的画风**优先项目视觉手册**；**未选视觉手册时，默认以本手册「导演专属电影美学」控制静态画风**。本风格根仅指导视频镜头语言与画面氛围，不覆盖静态画风。
> **角色演出层**：人物情绪/表情/眼神/微动作的表演提示统一以总控「微表情表演」技能为准，适用于所有导演，与本手册叠加使用、互不替代。
```
