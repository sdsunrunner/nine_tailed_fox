## 三、生产规范（各篇通用）

1. **立项**：新建 Project → 按总表设置 视觉手册 + 导演手册 + 短片时长（建议 10-30）+ 画幅（16:9 横版 864×480）
2. **剧本**：小说页粘贴原著对应篇目 → 设定短片时长 → AI 改编（整片三幕，分集=技术切割，无每集钩子）
3. **拆镜**：storyboard-split（按场导演覆盖可用）；分镜 ≤15s、videoDesc ≤350 字/镜
4. **资产**：角色/场景/道具按视觉手册画风生成（Z-Image Turbo，本机 ComfyUI 9312）
5. **视频**：按场分段生产（每段 ≤5 分钟，MiniMax H3 Director 串联），段尾落在场景/镜头自然边界
6. **风格一致性**：静态画风=视觉手册；动态镜头语言=导演手册；情绪表演=微表情技能叠加

## 五、方言配音规划（2026-08-31 定）

> 原则：各篇按**故事地域**选方言，增强地域质感与辨识度；方言口音以「能听懂、够味」为度，不强求纯正。配音 TTS 支持方言时直接合成；不支持时按方言腔调配音或方言台词+普通话旁白。

| 篇章 | 故事地域 | 配音方言 | 说明 |
|------|---------|---------|------|
| **铸剑** | 楚地（春秋） | **普通话**（正剧腔） | 偏正剧，用普通话保持庄重；人物情绪靠表演而非方言 |
| **奔月** | 后羿·东夷（齐鲁一带） | **山东话** | 后羿射日传说多附会东夷/山东；**故事取「英雄考编·体制内不愁吃喝」的荒诞感**——射日英雄加入体制混日子，山东话的直率憨厚衬反差喜感（已定） |
| **理水** | 大禹治水·中原/晋南（尧都平阳、禹都安邑） | **山西话/晋语**（硬朗诙谐） | 大禹治水传说核心区在晋南；晋语保留入声、硬朗诙谐，官场讽刺戏自带硬气味；与河南话（非攻）/陕西话（出关）/西北话（补天）均不同源（已定） |
| **补天** | 女娲·陇西/天水一带 | **西北话（甘肃/陕西腔）** | 补天神话地域模糊，取陇西女娲传说，西北腔的厚重 |
| **采薇** | 伯夷叔齐·孤竹（河北/辽西）→ 南迁首阳山 | **南方方言语调**（吴语/江南腔） | 二人周游南迁，江南软语衬「克制的哀」与迂腐书生气 |
| **非攻** | 墨子·宋/鲁（河南/山东交界） | **河南话**（刚直执拗）+ **豫剧元素** | 墨子周游止战，河南话的直白执拗；**机锋对话段配豫剧旋律背景音乐，人物对话加豫剧念白腔调**（拖腔/板式感，只加一点不喧宾夺主）（已定） |
| **出关** | 老子·函谷关（豫西）西行入秦 | **陕西话（语调柔软）** | 老子出函谷关西入秦地，陕西话但**语调柔软悠缓**——不取秦腔刚硬，取关中话的温厚从容，合老子淡泊（已定） |
| **起死** | 庄子·宋国（河南商丘一带） | **陕西豫东腔调 + 秦腔唱腔** | 偏舞台风格：庄子与骷髅辩难如戏台演出，**加入秦腔调调**（拖腔、高亢、板式感），荒诞闹剧的舞台化（已定） |

> 补充：**8 篇方言全部已定**；完整声音方案（方言/戏曲/配乐/音效）见工作区 `故事新编/_概念图调研/声音设计.md`。
> 落地：配音在九尾狐 TTS/配音环节接入；方言合成能力以所选 TTS 服务支持为准（Minimax TTS / 云端 TTS 方言支持度待验证）；起死的秦腔调若 TTS 不支持，可配音后叠加秦腔唱段或板胡配乐；非攻的豫剧念白腔调同样以 TTS 能力为准，豫剧旋律背景音乐可在配乐环节叠加（板胡/梆子/豫剧过门）。
